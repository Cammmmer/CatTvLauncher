# 全局架构

## 模块结构

依赖方向：`:app` → `:appInfo` → `:commom`

| 模块 | 包名 | 职责 |
|---|---|---|
| `:app` | `com.wuyi.tv` | 桌面应用本体：UI 与交互，ViewBinding 已启用 |
| `:appInfo` | `com.wuyi.tv.appinfo` | 应用信息领域模块：查询已安装应用、桌面条目模型、排序/置顶优先级，不含 UI |
| `:commom` | `com.wuyi.tv.common` | 公共基础能力：日志、ContextHolder、基类、VersionConfig（"commom" 为历史拼写错误，模块名与目录名均保留） |

注意：`settings.gradle.kts` 中 include 的是 `:appinfo`，磁盘目录为 `appInfo`，详见 CLAUDE.md 关键约束。

## 应用入口

- `TvApplication`：`onCreate` 中初始化 `ContextHolder.context`（全局 Application 引用）与日志前缀 `WTv_`。
- `MainActivity`：FragmentActivity，HOME 入口，Manifest 关键配置见 CLAUDE.md 关键约束。
- UI 在 `activity_main.xml` 中以 `<fragment>` 静态挂载，层级自下而上：
  1. `WallpaperFragment`（全屏背景层）
  2. `AppListFragment`（应用列表层，叠加其上）

## 核心数据流（应用列表）

```
AppListFragment
  → AppInfoViewMode（ViewModel，LiveData<List<AppInfo>>）
  → AppInfoRepository（object 单例，内存缓存，Dispatchers.IO）
  → AppInfoManager（PackageManager 查询 CATEGORY_LAUNCHER Activity）
```

加载完成后按 `appConfigMap` 中的 `priority` 降序排序（置顶项定义在 `AppConstant.kt`）。详见 `doc/模块/应用列表/技术文档.md`。
