# 文档目录说明

本目录存放项目详细材料，按模块细分。`doc/模块/` 下每个模块目录必须包含：

- `需求文档.md`：功能需求、交互行为、当前状态与待办
- `技术文档.md`：代码位置、实现方案、数据流、修改指引

## 目录索引

| 路径 | 说明 | 主要代码位置 |
|---|---|---|
| `全局约束.md` | **强制约束，编码前必须读取，编码过程第一要求** | - |
| `全局架构.md` | 模块结构、依赖方向、应用入口与核心数据流 | - |
| `模块/应用列表/` | 桌面核心功能：加载已安装应用、置顶排序、点击启动应用 | `app/.../tv/applist`、`appInfo` 模块 |
| `模块/壁纸/` | 壁纸功能（`:wallpaper` 模块），当前为占位实现 | `wallpaper/` 模块 |
| `模块/公共基础/` | commom 模块：全局 Context、统一日志、基类 | `commom` 模块 |

## 使用方式

- **编码前：必读 `全局约束.md`，编码过程中作为第一要求**
- 了解整体结构：读 `全局架构.md`
- 修改某个模块：先读 `doc/模块/<模块名>/` 下的《需求文档》与《技术文档》，再动代码
- 新增模块：在 `doc/模块/` 下新建模块目录，补充需求与技术文档，并在 `CLAUDE.md` 的文档目录表中登记
