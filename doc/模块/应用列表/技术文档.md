# 应用列表 — 技术文档

## 代码位置

| 层 | 文件 |
|---|---|
| UI | `app/src/main/java/com/wuyi/tv/applist/ui/AppListFragment.kt` |
| Adapter | `app/src/main/java/com/wuyi/tv/applist/adapter/AppListViewAdapter.kt` |
| ViewModel | `app/src/main/java/com/wuyi/tv/applist/viewmodel/AppInfoViewMode.kt` |
| 领域层 | `appInfo/src/main/java/com/wuyi/tv/appinfo/` 下：`bean/AppInfo.kt`、`bean/LauncherItem.kt`、`manager/AppInfoManager.kt`、`repo/AppInfoRepository.kt`、`constant/AppConstant.kt`、`constant/AppInfoConfig.kt` |

## 数据流

```
AppListFragment.onCreateView
  ├─ initView()
  │    ├─ initAppList(): 横向 LinearLayoutManager + AppListViewAdapter，注册条目点击回调
  │    └─ 观察 appInfoModel.appInfoResult（LiveData），数据到达后 adapter.setData()
  └─ initData()
       └─ appInfoModel.loadAppInfo()
            └─ viewModelScope.launch
                 └─ AppInfoRepository.loadAppInfo()（Dispatchers.IO）
                      ├─ 首次调用：AppInfoManager.getInstalledApplications(ContextHolder.context)
                      │    └─ PackageManager.queryIntentActivities(ACTION_MAIN + CATEGORY_LAUNCHER)
                      ├─ 按 appConfigMap[componentName]?.priority ?: 0 降序排序
                      └─ 缓存进 Repository 内存列表（后续调用直接返回缓存）
```

条目点击：`AppListViewAdapter.ItemClickListener` → `LogEvent.onClick` → `LauncherItem.onClick(context)`。

## 关键设计

- **`LauncherItem` 接口**（`getTitle()` / `getLogo()` / `onClick(context)`）抽象"可展示于桌面的条目"，`AppInfo` 是当前唯一实现。新增条目类型（快捷方式、文件夹等）时实现该接口即可被 adapter 复用。
- **启动方式**：`AppInfo.onClick` 通过 `getLaunchIntentForPackage(componentName.packageName)` 启动；intent 为 null 时走 `LogEvent.nullException` 记录。
- **渲染方式**：adapter 将图标 Drawable 直接设为条目根视图背景（`setBackgroundDrawable`），标题 `titleView` 的赋值代码被注释掉了。
- **ViewModel 作用域**：`AppInfoViewMode` 通过 `ViewModelProvider(requireActivity())` 获取，绑定在 Activity 级，配置变更不丢数据。

## 修改指引

- **置顶/排序调整**：`AppConstant.kt` 添加 `ComponentName`（包名 + 启动 Activity 类名），`AppInfoConfig.kt` 的 `appConfigMap` 中配置 `priority`（越大越靠前）。
- **隐藏应用**：使用 `AppInfoConfig.enable`（字段已定义，过滤逻辑尚未实现）。
- **强制刷新列表**：`AppInfoRepository.appList` 为内存缓存，需清空后重新 `loadAppInfo()`。
