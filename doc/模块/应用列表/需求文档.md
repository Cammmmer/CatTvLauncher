# 应用列表 — 需求文档

## 功能概述

桌面主界面以横向列表展示设备上所有可启动的应用，用户通过遥控器选中并点击后启动对应应用。

## 需求点

1. 自动加载设备上所有带 `CATEGORY_LAUNCHER` 的应用
2. 置顶与排序：B站（云视听小电视）与夸克网盘固定排在最前，其余应用按系统返回顺序展示
3. 点击条目启动对应应用，并记录点击日志
4. 列表数据在进程内缓存，避免重复查询 `PackageManager`

## 交互

- 横向 RecyclerView，焦点导航由系统处理
- 条目无标题文字，以应用图标作为条目背景展示
- 点击条目：记录点击日志（`LogEvent.onClick`）并启动应用
