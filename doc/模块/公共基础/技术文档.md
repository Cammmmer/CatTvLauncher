# 公共基础 — 技术文档

## 代码位置

`commom` 模块，包 `com.wuyi.tv.common`：

| 文件 | 职责 |
|---|---|
| `global/ContextHolder.kt` | 全局 Application 引用与资源快捷方法 |
| `log/LogUtils.kt` | 日志包装 |
| `log/LogEvent.kt` | 事件日志 |
| `utils/ui/BaseActivity.kt` | Activity 基类（当前为空壳，继承 AppCompatActivity） |
| `utils/ui/BaseFragment.kt` | Fragment 基类（可见性封装） |
| `utils/VersionConfig.kt` | 版本信息 |

## ContextHolder

- `object`，`lateinit var context: Application`，由 `TvApplication.onCreate` 赋值。
- 提供 `getDimension` / `getString` / `getColor` 资源快捷方法。

## 日志

- **LogUtils**：包装 `android.util.Log`。tag 必须用 `LogUtils.TAG("Name")` 创建（惯例为文件级 `private val TAG`），运行时统一加 `WTv_` 前缀（`TvApplication` 中 `setTagPrefix("WTv_")`）。消息为 null 时输出 `"msg is null"` 兜底；异常堆栈使用 `e(tag, msg, tr)`。
- **LogEvent**：`onClick`（点击事件）、`nullException`（非常规空异常），内部走 `LogUtils.i`。
- 项目约束：不要直接使用 `android.util.Log`。

## BaseFragment 可见性封装

- 将 `onResume`/`onPause`、`onHiddenChanged`、`setUserVisibleHint` 统一为可见性状态机，回调 `onVisible()` / `onVisibleFirst()` / `onInvisible()`。
- 可见性向子 Fragment 传播（`determineChildFragmentVisible/Invisible`）；父 Fragment 不可见时，子 Fragment 强制不可见。
- 判定条件：`isResumed && !isHidden && userVisibleHint && 当前不可见`。

## VersionConfig

- 可变字段 `appVersion` / `branch` / `carPlatform`，默认 `"unknown"`；`println()` 以 error 级别输出。
- 当前无赋值处，预留给构建流程注入。
