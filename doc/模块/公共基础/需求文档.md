# 公共基础 — 需求文档

## 功能概述

`commom` 模块提供全项目共用的基础能力，不含业务逻辑。

## 需求点

1. **全局 Context**：非 UI 场景（Repository 等）可获取 Application Context，并提供资源快捷读取
2. **统一日志**：统一 tag 前缀（`WTv_`）、统一入口、空消息兜底
3. **事件日志**：点击事件、非常规空异常的独立记录入口
4. **基类**：`BaseActivity` / `BaseFragment`（统一可见性回调）
5. **版本信息**：`VersionConfig` 记录 appVersion / branch / carPlatform
