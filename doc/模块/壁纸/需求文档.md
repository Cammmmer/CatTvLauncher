# 壁纸 — 需求文档

## 功能概述

桌面背景层，位于所有内容之下，用于展示壁纸 / 背景视觉。独立为 `:wallpaper` 模块开发。

## 需求点

- 作为桌面最底层全屏展示，不遮挡、不响应交互（布局根节点及子 View 均已设置 `clickable` / `focusable` 为 false）
- 默认静态壁纸由模块内 `ImageView`（`wallpaper_view`）展示，支持后续运行时切换

## 当前状态

默认静态壁纸已由 `WallpaperFragment` 布局中的 `ImageView` 展示（`scaleType=centerCrop`）；`initView()` 暂无逻辑。后续需求（壁纸切换、动态背景等）待定义。
