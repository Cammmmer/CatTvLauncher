# 壁纸 — 技术文档

## 模块信息

- Gradle 模块：`:wallpaper`（目录 `wallpaper/`，与 settings 中 include 名大小写一致），namespace `com.wuyi.tv.wallpaper`
- 依赖：`project(":commom")`、`libs.androidx.appcompat`（提供 `androidx.fragment`）
- ViewBinding 已启用（`FragmentWallpaperBinding`）

## 代码位置

| 类型 | 路径 |
|---|---|
| Fragment | `wallpaper/src/main/java/com/wuyi/tv/wallpaper/ui/WallpaperFragment.kt` |
| 布局 | `wallpaper/src/main/res/layout/fragment_wallpaper.xml` |
| 默认壁纸图 | `wallpaper/src/main/res/drawable/wallpaper_default.jpg` |
| Manifest | `wallpaper/src/main/AndroidManifest.xml`（空，无权限） |

## 实现说明

- **挂载方式**：app 的 `activity_main.xml` 以 `<fragment>` 静态挂载，类名 `com.wuyi.tv.wallpaper.ui.WallpaperFragment`，位于 `FrameLayout` 底层（第一个子 View），`AppListFragment` 叠加其上。
- **布局结构**：FrameLayout 根节点（全屏，不可点击/聚焦）+ `ImageView`（id `wallpaper_view`，全屏，`scaleType=centerCrop`，src 指向 `wallpaper_default`）。
- **职责归属**：壁纸展示完全由 `WallpaperFragment` 的 ImageView 承担（未来切换/动态壁纸的落点）；app 主题 `Theme.WuyiTV` 未设置 `android:windowBackground`。
- **TV 焦点约束**：壁纸层所有节点 `clickable` / `focusable` / `focusableInTouchMode` 必须为 false，不得抢占遥控器焦点。

## 扩展指引

- 壁纸切换逻辑写在 `WallpaperFragment.initView()` 中，操作 `rootViewBinding.wallpaperView`（沿用 `inflate(...).apply {}` 的项目惯用写法）。
- 保持 `activity_main.xml` 中的层级顺序：壁纸层必须在 `AppListFragment` 之下。
