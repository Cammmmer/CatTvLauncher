# 壁纸 — 技术文档

## 代码位置

- `app/src/main/java/com/wuyi/tv/ui/WallpaperFragment.kt`
- 布局：`app/src/main/res/layout/fragment_wallpaper.xml`

## 实现说明

- 在 `activity_main.xml` 中以 `<fragment>` 静态挂载，位于 `FrameLayout` 底层（第一个子 View），`AppListFragment` 叠加其上。
- 当前 `initView()` 为空，无业务逻辑；ViewBinding 已生成 `FragmentWallpaperBinding`。

## 扩展指引

- 壁纸展示逻辑写在 `WallpaperFragment.initView()` 中，使用 `FragmentWallpaperBinding`（沿用 `inflate(...).apply {}` 的项目惯用写法）。
- 保持 `activity_main.xml` 中的层级顺序：壁纸层必须在 `AppListFragment` 之下。
